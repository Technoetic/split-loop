# LOOP / SPLIT

**한 루프, 두 가지 임무. 작업을 나누고 결과를 지켜라.**

[바로 플레이](https://technoetic.github.io/split-loop/)

Martin Fowler의 Split Loop를 직접 체험하는 한국어 액션 퍼즐입니다.

- 90초 챌린지와 시간제한 없는 연습
- 8개 라운드: 안전한 분리 6개, 보류가 필요한 문제 2개
- 같은 전체 데이터의 작업을 목적별 두 순차 루프로 배치
- 카드 선택/목적지 버튼/드래그, 카드 내부·전체 루프 순서 변경
- 원본과 결과 비교, 구체적인 반례, 문제별 18개 입력
- 콤보·점수·일시정지·진행 저장/이어하기·로컬 상위20개 기록
- 키보드 조작과 모바일 화면 대응

## 조작

카드를 클릭한 다음 1 또는 2로 목적지 루프를 정합니다. 위·아래 방향키로 카드를
고르고, Backspace로 회수하고, Space로 검사합니다. Esc는 일시정지입니다.
버튼과 드래그도 사용할 수 있습니다.

첫 루프가 같은 전체 데이터를 끝까지 처리한 뒤 둘째 루프가 시작됩니다.
순서나 중간값 의존성 때문에 결과를 지킬 수 없다면 ‘분리 보류’를 선택하세요.

## 로컬 실행

Node.js 22 이상이 필요하며 외부 패키지 설치는 필요하지 않습니다.

    npm start

기본 주소는 http://127.0.0.1:8794/split-loop/ 입니다.

    npm test
    npm run build

정적 결과물은 dist/입니다. GitHub Actions가 검사·빌드한 이 폴더를 Pages로 배포합니다.
해시 경로를 사용하므로 플레이·가이드·기록 화면의 직접 링크와 새로고침을 지원합니다.

## 저장과 업데이트

진행과 기록은 현재 브라우저의 localStorage에 저장됩니다. 다른 도메인이나 기기와
공유되지 않으므로 localhost의 기록이 공개 주소로 자동 이전되지는 않습니다.
계정 동기화나 온라인 순위, 로컬 기록의 변조 방지 기능은 아닙니다.

HTML의 현재 build ID와 신선한 version.json을 비교합니다. 새 빌드나 롤백을 감지하면
다음 안전한 이동에서 목표 URL의 새 문서를 불러옵니다. 진행 중인 게임과 저장 작업은
먼저 보호합니다. 해시가 붙은 자산과 직전 성공 배포의 자산도 함께 제공합니다.
정적 호스트의 캐시 전파에는 지연이 있을 수 있습니다.

## 학습 범위

문제별 18개 입력과 유한한 명령 언어를 비교하는 교육 게임입니다.
임의의 실제 프로그램에 대한 일반 동치 증명이나 성능 개선 보장은 아닙니다.
물리 휴대폰/입력 장치·오디오 청취·실제 BFCache 복원은 별도 검증 대상입니다.
